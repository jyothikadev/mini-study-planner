# mini-study-planner
Mini Study Planner with task management, due dates, priority indicators and local storage.
A simple Study Planner built using HTML, CSS, and JavaScript.

## Features

* Add tasks
* Delete tasks
* Mark tasks as completed
* Filter tasks (All, Completed, Pending)
* Due dates
* Automatic priority indicators
* Task counters
* Local Storage support

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter a task.
2. Select a due date.
3. Click **Add Task**.
4. Mark tasks as completed when finished.
5. Use filters to view different tasks.
